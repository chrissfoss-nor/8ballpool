# 8ballpool

An AI-powered 8-ball pool game that you can play against.

## What Can I Help You With? / Hva kan du hjelpe meg med?

This 8-ball pool AI project can help you with:

- **Practice Your Pool Skills**: Play against an AI opponent to improve your game strategy and shot selection
- **Learn Pool Rules**: Understand the rules of 8-ball pool through gameplay
- **Entertainment**: Enjoy a game of pool anytime, anywhere without needing a physical table or human opponent
- **AI Challenge**: Test your skills against an intelligent computer opponent
- **Game Analysis**: Learn from AI moves and strategies to become a better player

## Features

- 🎱 Classic 8-ball pool gameplay
- 🤖 AI opponent to play against
- 🎮 Interactive game experience
- 📊 Learn from AI strategies
